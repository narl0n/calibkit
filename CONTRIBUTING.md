# Contributing

1. Fork the repository and create a feature branch: `git checkout -b feature/my-change`.
2. Install in development mode: `pip install -e ".[dev]"`.
3. Make your change and add tests under `tests/`.
4. Run `ruff check .` and `pytest` locally; CI runs the same checks on Python 3.10-3.13.
5. Use short, imperative commit messages (e.g. `Add adaptive-bin ECE`).
6. Open a pull request against `main` and fill in the template.

Bugs and ideas are tracked through GitHub Issues; please use the provided templates.
